# Startup Backlinks

**中文** | [English](./README_EN.md)

一个经过人工筛选和验证的startup外链库，帮助**初创企业、SaaS 产品、AI 工具和独立开发者**发布产品、触达早期用户并获得相关反向链接。

本项目专注于提供可实际操作、拥有公开提交入口的推广机会，不收录失效目录、链接农场或缺少具体信息的泛泛列表。目前收录了来自 [BlinkLib](https://blinklib.com/backlink-resources) 的 **65 个公开资源**。如需最新数据、筛选功能和提交管理工具，请访问在线目录。

> 提交规则、价格、流量和链接属性可能随时变化，请在提交前自行核实各平台的最新要求。

## 为什么创建这个列表？

网上的许多外链列表已经过时，或者没有说明是否真的可以提交产品。本列表优先收录与初创企业和软件产品相关、提交入口仍然有效、能够带来推荐流量或品牌曝光，并且可以生成公开产品页或资料页的平台。

每条资源包含以下信息：

| 字段 | 说明 |
| --- | --- |
| 平台 | 网站或平台名称；如有明确入口，则直接链接到提交页面 |
| 费用 | 免费、付费或同时提供两种方案 |
| DR | 可获取时提供 Domain Rating（域名评级） |
| 月访问量 | 网站月访问量估算值 |
| 链接属性 | dofollow、nofollow、UGC、无直接链接或未知 |

## 参与贡献

如果你发现了失效链接，或者有值得收录的初创企业推广资源，欢迎提交 Issue 或 Pull Request。

请尽可能提供以下信息：

```text
名称：
网站：
提交地址：
分类：
价格：
链接属性：
是否需要审核：
备注：
```

请勿提交垃圾网站、PBN、链接农场、失效目录、无关的通用网站，或没有公开提交方式的网站。我们的目标是让这份列表始终保持实用、整洁并经过验证。

如需持续维护、支持搜索筛选的完整数据，请访问 [BlinkLib 外链库](https://blinklib.com/backlink-resources)。
